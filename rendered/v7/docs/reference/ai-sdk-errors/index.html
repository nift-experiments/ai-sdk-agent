The AI SDK exposes typed errors so applications can handle expected failure modes without matching error message strings.

Importing Errors

The application package is named ai, not @ai-sdk/ai. It re-exports common provider-level errors from @ai-sdk/provider together with the higher-level errors raised by AI SDK Core:

import { APICallError, NoObjectGeneratedError } from 'ai';

Provider implementations that depend directly on @ai-sdk/provider can import its provider-level errors from that package instead:

import { APICallError, InvalidResponseDataError } from '@ai-sdk/provider';

Migrating to Typed Error Handling

Replace message matching or an unconditionally generic catch block with the most specific static isInstance guard available. Check AISDKError last when you need a fallback for any AI SDK error:

import { AISDKError, APICallError, generateText } from 'ai';

try {
  await generateText({
    model,
    prompt: 'Write a vegetarian lasagna recipe for 4 people.',
  });
} catch (error) {
  if (APICallError.isInstance(error)) {
    console.error('Provider request failed:', error.statusCode);
    return;
  }

  if (AISDKError.isInstance(error)) {
    console.error('AI SDK error:', error.name);
    return;
  }

  throw error;
}

Prefer ErrorClass.isInstance(error) over error instanceof ErrorClass when the class provides it. The static guard also works when multiple AI SDK package versions are loaded.

Common Failure Modes

Failure modeError to check
A provider request fails because of a network error or non-success responseAPICallError
Automatic retries are exhaustedRetryError
A provider reports an error after a response stream has startedStreamProviderError
A structured output cannot be parsed or validatedNoObjectGeneratedError; inspect its cause for JSONParseError or TypeValidationError
A generation call returns no usable outputNoOutputGeneratedError or the modality-specific No*GeneratedError
A model calls a missing tool or supplies invalid tool inputNoSuchToolError or InvalidToolInputError
Tool-call repair failsToolCallRepairError
A response violates an enforced toolChoiceToolChoiceViolationError
Message history contains unresolved tool calls or invalid approvalsMissingToolResultsError, InvalidToolApprovalError, or InvalidToolApprovalSignatureError
A provider or model cannot be resolvedNoSuchProviderError, NoSuchModelError, or NoSuchProviderReferenceError
A provider response is empty, malformed, or invalidEmptyResponseBodyError, JSONParseError, or InvalidResponseDataError
The requested model or provider does not support a capability or specification versionUnsupportedFunctionalityError or UnsupportedModelVersionError
UI messages cannot be converted or a UI message stream is invalidMessageConversionError or UIMessageStreamError
