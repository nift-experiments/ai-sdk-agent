Harness adapters connect HarnessAgent to a specific agent runtime. They are the harness equivalent of AI SDK model providers: each adapter wraps one runtime and normalizes its sessions, stream events, tools, usage, lifecycle state, and configuration into the harness contract.

AI SDK Harness Adapters

The AI SDK includes the following harness adapters:

  • Cline (@ai-sdk/harness-cline)
